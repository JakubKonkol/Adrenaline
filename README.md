# Adrenaline

Aplikacja desktopowa na Windows: wyszukaj film lub odcinek, wybierz wydanie i język napisów, kliknij Pobierz i otwórz gotowy folder z filmem i napisami.

Projekt jest na etapie planu. Plan implementacji: [`docs/implementation-plan/`](docs/implementation-plan/README.md). Zasady pracy: [`CLAUDE.md`](CLAUDE.md).
