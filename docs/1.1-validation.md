# Version 1.1.0 validation

Changes and user-visible behavior: [release notes](releases/1.1.0.md).

Automated coverage includes:

- A verified completion event arriving before the last progress tick, plus repair of an existing completed job at 99% after restart.
- Completed movies with missing subtitle credentials and subsequent successful manual retry.
- NapiProjekt's first-10-MiB MD5, verification parameter, gzip response, negative answers and invalid payloads.
- Napisy24 form fields, file-size/hash matching, binary ZIP separator, authentication and negative answers.
- Provider failure isolation, request deduplication, cached negative results and downloading through the chosen provider only.
- Conversion of time-based Polish TXT and frame-based MicroDVD to SRT.
- TV quality filters including unknown resolution, clearing empty results, sorting, explicit subtitle yes/no, concrete file choice and continuing without subtitles after search failure.
- TV API ownership, subtitle reference validation and saved choices, and TMDB list/genre endpoints.

Local verification on 2026-10-17:

- `npm run check`: lint and typecheck passed; 477 tests passed, 4 skipped (63 test files, 2 skipped).
- `npm run build` and `npm run build:tv`: passed; Tizen widget content prepared as 1.1.0.
- `npm run test:smoke`: passed on Windows/Electron; input latency p95 42.9 ms with three downloads and twenty samples.
- Android `assembleRelease`: passed in the existing `ghcr.io/cirruslabs/android-sdk:35` container with the final 1.1.0 TV web assets (development signing for local validation).
- `node scripts/check-version-tag.mjs v1.1.0` and `git diff --check`: passed.

Process lifecycle tests run outside the filesystem sandbox because Windows `taskkill /T` is unavailable inside it. Provider tests use synthetic responses; no new live account or physical TV acceptance is implied. Native engine, installer packaging and signed release artifacts are checked by the tag-triggered GitHub workflow.

Manual checks after installation:

1. Set Polish subtitles, enable NapiProjekt, leave OpenSubtitles credentials empty and download a permitted test video. Confirm the film reaches 100% and enters Library even if no subtitles exist.
2. Repeat with OpenSubtitles and Napisy24 API access. Check provider labels, file matching, and the Napisy24 comment link. Retry subtitles from download details without restarting the movie download.
3. On TV, exercise the filters using the remote and scroll the added home-screen collections. Choose a torrent, select Yes, then choose a subtitle file. Repeat with No and with hash matching after download.
4. Samsung/Tizen: Subtitles → Subtitle settings → Sync, then left/right and OK reset. Android: MENU → Audio & subtitles → Subtitle sync; adjust earlier/later, reset, seek, pause and resume. Use a separately rendered subtitle track; subtitles burned into the picture cannot be adjusted independently.
